日本語

LiTiles（以下「本アプリ」）は、並んだタイルを、指でなぞる、音に合わせる、時刻や文字列を表示するなどして光らせて楽しむアプリです。ライフゲームやスネークなどのゲームも遊べます。

収集するデータ

本アプリは、利用者を特定する情報、利用状況、診断情報、位置情報、連絡先情報その他の個人データを収集しません。広告SDK、分析SDK、トラッキング機能も使用しません。

マイクと音楽ファイル

入力源に「音（内蔵マイク）」を選んだ場合に限り、マイクの音を使います。音は、タイルを光らせるために、端末の中で周波数ごとの強さを分析するだけです。録音も保存もせず、外部へ送信することもありません。マイクの使用は、初めて使うときに、利用者の許可を求めます。許可は、端末の設定でいつでも変更できます。

入力源に「音楽（ファイルを再生）」を選んだ場合に限り、利用者が選んだ音楽ファイルを、端末の中で再生し、分析します。ファイルは、本アプリの外へ送信されません。

文字列・プリセット・設定

利用者が入力した文字列、プリセット、色や数量などの設定は、利用者のデバイス内に保存されます。本アプリが、これらのデータを開発者のサーバーその他の外部サービスへ送信することはありません。

データの共有

本アプリは、利用者のデータを第三者と共有、販売、または広告目的で利用しません。利用者がプリセットを書き出す操作をした場合に限り、利用者が選択した共有先へファイルが送られます。

English

LiTiles (the “App”) is an app for enjoying a grid of tiles that light up by touch, by sound, or by displaying the time or text. It also includes games such as the Game of Life and Snake.

Data We Collect

The App does not collect personal information, usage data, diagnostic data, location data, contacts, or other personal data. It does not use advertising SDKs, analytics SDKs, or tracking technologies.

Microphone and Music Files

The App uses the microphone only when the user selects the built-in microphone as an input source. The sound is analyzed on the device only, to measure the strength of each frequency band and make the tiles light up. It is not recorded, saved, or sent anywhere. The App asks for the user’s permission the first time the microphone is used, and the user can change this permission at any time in the device settings.

The App plays and analyzes a music file only when the user selects the music input source and chooses a file. The file is played and analyzed on the device and is not sent outside the App.

Text, Presets, and Settings

Text entered by the user, presets, and settings such as colors and tile counts are stored on the user’s device. The App does not transmit this data to the developer’s servers or to other external services.

Data Sharing

The App does not share, sell, or use user data for advertising. A file is sent to a destination only when the user explicitly chooses to export a preset.
